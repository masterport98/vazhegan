# گنجینهٔ واژگان

۳۲۸ واژه و اصطلاح سطح‌بالای فارسی، دسته‌بندی‌شده بر اساس کارکرد،
رجیستر، شکل، کانال و تناسب کاربرد.

یک وب‌اپ تک‌فایلی و بدون وابستگی. روی گوشی قابل نصب است
(Chrome ← منوی سه‌نقطه ← Install app) و پس از اولین بارگذاری
کاملاً آفلاین کار می‌کند.

| فایل | کار |
|---|---|
| `index.html` | کل برنامه: داده، ظاهر و کد |
| `manifest.webmanifest` | نام، آیکون، رنگ و حالت نمایش |
| `sw.js` | سرویس‌ورکر؛ کش آفلاین |
| `.nojekyll` | غیرفعال کردن Jekyll در GitHub Pages |

A single-file Persian vocabulary reference, installable as a PWA.
